# Palm Pay — Frontend Web App

React 18 + Vite client application featuring:
- **Phase 1: Customer Web App** (Personal wallet, palm registration, 1:1 contactless payments, PIN fallback, transaction history, GDPR privacy controls).
- **Phase 2: Merchant POS Web App** (Retail checkout scanner performing 1:N biometric identification).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build Production Bundle
```bash
npm run build
```

## 🎨 Design System
- Built on modern Vanilla CSS with dark/light mode toggle.
- Lucide React iconography.
- Real-time biometric camera overlays with laser sweep animation.
